# Quora-Style Posts Application

A Quora-inspired CRUD web application built using **Node.js**, **Express.js**, and **EJS**.  
This project demonstrates RESTful routing, server-side rendering, and basic post management functionality.

---

## 🚀 Features

- Create new posts
- View all posts
- View post details
- Edit existing posts
- Delete posts
- Server-side rendering using EJS
- Clean and responsive UI with CSS

---

## 🛠 Tech Stack

- Node.js
- Express.js
- EJS (Embedded JavaScript Templates)
- HTML5
- CSS3

## ⚙️ Installation & Setup

1. Clone the repository
   ```
   git clone https://github.com/your-username/your-repo-name.git
   ```

2. Navigate to the project folder
   ```
   cd your-repo-name
   ```

3. Install dependencies
   ```
   npm install
   ```

4. Start the server
   ```
   node index.js
   ```

5. Open in browser
   ```
   http://localhost:8080/posts
   ```
